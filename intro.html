안녕하세요. 여러분과 피그마 수업을 함께하게 된 장지은입니다.
2005년부터 디자인 관련 일을 시작했고, 디자인을 하다 보니 퍼블리싱과 개발에도 관심이 생겨 공부하면서 웹 퍼블리셔로 일을 해왔습니다.
피그마가 없던 시절부터 일을 해와서 저도 피그마를 아주 오래 사용한 사람은 아닙니다. 하지만 실제 업무에서 디자인과 개발 사이를 연결하면서, 어떤 화면과 어떤 정리가 있어야 개발하기 편한지는 많이 경험해봤습니다.
이번 수업에서는 피그마로 예쁜 화면만 만드는 것보다,
화면이 어떤 구조로 만들어지고 어떤 규칙으로 정리되는지, 그리고 개발자에게 어떻게 잘 전달할 수 있는지를 함께 배워보려고 합니다.
피그마를 꼭 디자이너의 도구라고 생각하지 말고, 내가 만들 화면을 설계하고 정리하는 도구라고 생각하면서 같이 해봤으면 좋겠습니다.

잘 부탁드립니다!

05 · SECTION + CONTAINER

영역의 역할과 내용의 폭을 나눕니다.

SECTION · 전체 영역 / 배경100% WIDTH
CONTAINER · 실제 내용 영역MAX-WIDTH
Title · Text · Button · Card · Image

Section

화면 전체 영역을 나눕니다. 섹션별 배경색, 배경 이미지, 큰 여백을 가질 수 있습니다.

Container

실제 콘텐츠가 들어가는 폭입니다. 일정한 정렬 기준과 max-width를 관리합니다.

08 ·

피그마로 멋진 웹페이지를 만들어봅시다.

우리가 해야할 것들

  1. 지난 시간에 만든 와이어프레임을 엽니다.
  2. Typography · Color · 기준을 정하고 등록합니다.
  3. Header · Main · Footer의 큰 구조를 만듭니다.
  4. Header부터 시작해 Section과 Container를 구성합니다.
  5. 필요한 콘텐츠를 하나씩 조립하면서 화면을 채워갑니다.
  6. 내용이 함께 움직여야 하는 부분에 Auto Layout을 적용합니다.
  7. 반복되는 UI는 Component로 관리합니다.
