05 · SECTION + CONTAINER

영역의 역할과 내용의 폭을 나눕니다.

SECTION · 전체 영역 / 배경100% WIDTH
CONTAINER · 실제 내용 영역MAX-WIDTH
Title · Text · Button · Card · Image

Section

화면 전체 영역을 나눕니다. 섹션별 배경색, 배경 이미지, 큰 여백을 가질 수 있습니다.

Container

실제 콘텐츠가 들어가는 폭입니다. 일정한 정렬 기준과 max-width를 관리합니다.

08 · TODAY'S PRACTICE

지난번 와이어프레임을
실제 구조로 바꿔봅시다.

오늘의 실습

  1. 지난 시간에 만든 와이어프레임을 엽니다.
  2. Typography · Color · 기준을 정하고 등록합니다.
  3. Header · Main · Footer의 큰 구조를 만듭니다.
  4. Header부터 시작해 Section과 Container를 구성합니다.
  5. 필요한 콘텐츠를 하나씩 조립하면서 화면을 채워갑니다.
  6. 내용이 함께 움직여야 하는 부분에 Auto Layout을 적용합니다.
  7. 반복되는 UI는 Component로 관리합니다.
