01 · INTRO

웹의 구조를 이해하고 피그마로 화면 설계하기

웹 화면을 만들 때는 단순히 원하는 위치에 요소를 배치하는 것이 아니라, 어떤 요소가 함께 움직이고 어떻게 연결되는지를 먼저 생각해야 합니다.
우리는 화면을 설계하는 도구로 Figma를 사용하고, Figma의 Auto Layout을 통해 웹의 구조를 직접 만들어 봅니다.

📐 화면을 구조로 보기

화면을 자유롭게 배치하는 것이 아니라 큰 상자 안에 작은 상자를 넣듯 영역과 요소의 관계를 생각합니다.

🧩 필요한 요소를 묶기

함께 움직여야 하는 요소를 하나의 묶음으로 만들고, 가로 또는 세로로 정렬하면서 화면의 구조를 완성합니다.

“무엇과 무엇을 하나로 묶을까?”를 생각하면서 웹 화면의 구조를 직접 만들어 보는 것이 목표입니다.

Step by Step

웹 화면 구조를 피그마로 함께 설계하기

먼저 전체 화면의 구조를 살펴보고,
필요한 곳에 Auto Layout을 적용하면서 화면이 어떻게 구성되는지 확인합니다.

생각하는 순서
구조를 생각한다 → 묶는다 → 방향을 결정한다 → Auto Layout을 사용한다.

1. 메인 프레임 & 레이아웃 그리드 설정

웹페이지를 만들기 위한 전체 도화지를 먼저 준비합니다. 화면의 크기와 콘텐츠가 놓일 기준을 설정합니다.

  • Desktop Frame 생성: 너비 1440px 크기의 프레임을 생성합니다.
  • Layout Grid 설정: Columns 12개, Margin 80px, Gutter 24px을 적용합니다.
  • 전체 구조 확인: 화면 안에 Header → Hero → Main Content → Footer가 들어갈 자리를 생각합니다.

수행평가 작업 및 제출 안내

함께 진행한 실습이 끝나면, 각자 기획하고 작성한 와이어프레임에 맞게 수행평가 작품 제작을 시작합니다.

📁 제출 파일 및 수행1 작업 안내

수업 실습 파일과 개인 수행평가 파일의 규칙을 반드시 준수하여 제출합니다.

1. 수업 같이하기 실습 파일명:

실습1-2-0-홍길동

※ '실습1 - 2학년 - 0반 - 이름' 의미

2. 개인 주제 수행평가 파일명:

수행1-2-0-홍길동

※ '수행1 - 2학년 - 0반 - 이름' 의미

⚠️ 제출 전 필수 확인사항

  • 제출 형태: 피그마 링크 제출 (Share > Anyone with the link can view 권한 설정 필수)
  • 제출용 파일 정리: 피그마 파일 내에는 최종 결과물 1개만 남기고, 불필요한 리소스는 깔끔하게 정리(삭제 또는 별도 페이지/파일 이동)해 주세요.
  • 기존 와이어프레임은 파일 내 다른 페이지로 이동합니다.

💡 수행1 작업 및 정리

  • 작업 준비: 기존에 작성한 개별 와이어프레임이 없는 경우, '같이하기 실습 파일'을 복제하고 본인의 주제 컨셉(기획, 색상, 글자 위계)에 맞춰 디자인을 진행합니다.
  • 와이어프레임에서 작업하기 까다로운 구조가 있다면 오토레이아웃으로 구현하기 쉬운 형태로 유연하게 변경해도 좋습니다.
  • 분량이 너무 많다면 필수 요소인 [상단 / 히어로 / 메인 콘텐츠 / 하단]을 기본으로 하고, [메인 콘텐츠]는 본인 주제에 맞춰 1개 영역만 선택하여 밀도 있게 제작합니다.
