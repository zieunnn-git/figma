Lesson Intro

💡 피그마를 통해 웹의 본질을 이해할 수 있을까?

피그마의 오토레이아웃 기능은 단순한 디자인 도구가 아닙니다. 실제 웹 코딩의 Flexbox, Padding, Margin 구조를 시각화해 주는 도구입니다.

피그마에서 Shift + A를 눌러 박스를 싸고 간격을 조절하는 과정이 바로 웹 화면이 지어지는 본질적인 원리입니다.
도구를 다루는 기술은 '시간문제'일 뿐입니다.
이 실습을 따라 하다 보면 자연스럽게 웹 구조의 핵심을 파악하게 됩니다.

❌ 겉모습만 만드는 사람 (현장 초급)

웹의 본질(구조)을 모른 채 AI에 질문함.
AI가 뱉어낸 '할루시네이션(거짓 코드)'을 걸러낼 지식이 없어 겉모습만 대충 구현하고, 생산성 없는 파편적 보수 작업만 반복함.

⭕ 구조를 통제하는 진짜 실력자

탄탄한 박스 구조와 웹의 본질을 완벽히 이해함.
AI의 결과물을 한눈에 검증하고 손쉽게 주도하므로, 작업의 효율과 완성도에서 비교조차 되지 않는 차이를 만들어냅니다.

Step by Step

오토레이아웃 마스터 함께 따라하기

남은 시간 동안 수행평가를 위해 오토레이아웃 중첩 구조를 차곡차곡 함께 만들어 갑니다.

1. 메인 프레임 & 레이아웃 그리드 설정 (프레임: Desktop 1440px)

도화지 규격과 가이드라인을 설정하는 단계입니다.

  • Desktop Frame 생성: 너비 1440px 크기의 프레임을 생성합니다.
  • Layout Grid 설정: Columns 12개, Margin 80px, Gutter 24px을 적용합니다.

2. 상단 (Header) 영역 구성 (로고 글자 크기: 24/1.3 | 메뉴 글자 크기: 18/1.5)

가로 정렬(Horizontal) 오토레이아웃을 적용합니다.

  • 구성 요소: 로고(본인 이름 작성) + 메뉴(Navigation) + 액션 버튼(CTA)
  • 오토레이아웃 적용: Shift + A를 눌러 가로 정렬을 적용하고 양끝 정렬(Space between) 또는 간격(Gap)을 설정합니다.

3. 히어로 (Hero Visual) 영역 구성 (히어로 글자 크기: 40/1.3 | 서브 설명: 24/1.5)

시선을 사로잡는 대표 비주얼 영역을 구성합니다.

  • 구성 요소: 메인 타이틀 텍스트 + 서브 설명 + CTA 버튼 + 메인 이미지
  • 중첩 구조: 텍스트와 버튼을 세로(Vertical) 오토레이아웃으로 감싸고, 메인 이미지와 가로(Horizontal)로 배치합니다.

4. 메인 콘텐츠 (Card List) 영역 구성 (영역 제목: 32/1.35 | 카드 제목: 22/1.4 | 카드 설명: 18/1.6)

반복되는 카드 구조와 영역 헤더를 차곡차곡 감싸는 중첩 레이아웃을 형성합니다.

  • 구성 요소: 영역 제목/설명 + 카드 목록 (카드 3~4개)
  • 카드 세부 요소: [카드 제목 + 이미지 영역 + 요약 설명 + 자세히 보기 버튼]으로 단탄하게 구성합니다.
  • 중첩 구조: 낱개 카드를 먼저 오토레이아웃으로 제작한 후, 카드 전체를 가로 박스로 다시 감싸줍니다.

5. 하단 (Footer) 영역 구성 (하단 로고: 20/1.3 | 텍스트 및 약관: 16/1.5)

사이트의 필수 마무리 정보를 정돈합니다.

  • 구성 요소: 로고(이름) + 사이트맵 + 약관 및 정책 + 카피라이트
  • 사이트맵 표기: [회사소개, 고객센터] 메뉴명을 명확히 표기합니다.
  • 약관 및 정책: [개인정보처리방침](굵게) + [이용약관]을 함께 배치합니다.
  • 카피라이트(Copyright) 작성: 본인의 영문 이름(성 제외)을 활용하여 표준 서식으로 기재합니다.

수행평가 1 작업 및 제출 안내

함께 진행한 실습이 끝나면, 각자 기획하고 작성한 와이어프레임에 맞게 수행평가 작품 제작을 시작합니다.

💡 와이어프레임 제작 팁

• 와이어프레임에서 작업하기 까다로운 구조가 있다면 오토레이아웃으로 구현하기 쉬운 형태로 유연하게 변경해도 좋습니다.

• 분량이 너무 많다면 필수 요소인 [상단 / 히어로 / 하단]을 기본으로 하고, [메인 콘텐츠]는 본인 주제에 맞춰 1개 영역만 선택하여 밀도 있게 제작합니다.
