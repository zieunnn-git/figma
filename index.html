01 · INTRO

웹의 구조를 이해하고 피그마로 화면 설계하기

웹 화면을 만들 때는 단순히 원하는 위치에 요소를 배치하는 것이 아니라, 어떤 요소가 함께 움직이고 어떻게 연결되는지를 먼저 생각해야 합니다.
우리는 화면을 설계하는 도구로 Figma를 사용하고, Figma의 Auto Layout을 통해 웹의 구조를 직접 만들어 봅니다.

📐 화면을 구조로 보기

화면을 자유롭게 배치하는 것이 아니라 큰 상자 안에 작은 상자를 넣듯 영역과 요소의 관계를 생각합니다.

🧩 필요한 요소를 묶기

함께 움직여야 하는 요소를 하나의 묶음으로 만들고, 가로 또는 세로로 정렬하면서 화면의 구조를 완성합니다.

오늘의 핵심: Auto Layout의 기능을 모두 외우는 것이 목표가 아닙니다. “무엇과 무엇을 하나로 묶을까?”를 생각하면서 웹 화면의 구조를 직접 만들어 보는 것이 목표입니다.

Step by Step

웹 화면 구조를 피그마로 함께 설계하기

먼저 전체 화면의 구조를 살펴보고, 큰 영역부터 작은 요소까지 차례대로 만들어 봅니다. 필요한 곳에 Auto Layout을 적용하면서 화면이 어떻게 구성되는지 확인합니다.

생각하는 순서
① 어떤 영역이 필요한가? → ② 어떤 요소가 함께 움직이는가? → ③ 하나의 묶음으로 만들 수 있는가? → ④ 가로인가, 세로인가? → ⑤ 필요한 곳에 Auto Layout을 적용한다.

1. 메인 프레임 & 레이아웃 그리드 설정 (프레임: Desktop 1440px)

웹페이지를 만들기 위한 전체 도화지를 먼저 준비합니다. 화면의 크기와 콘텐츠가 놓일 기준을 설정합니다.

  • Desktop Frame 생성: 너비 1440px 크기의 프레임을 생성합니다.
  • Layout Grid 설정: Columns 12개, Margin 80px, Gutter 24px을 적용합니다.
  • 전체 구조 확인: 화면 안에 Header → Hero → Main Content → Footer가 들어갈 자리를 생각합니다.

2. 상단 (Header) 영역 구성 (로고: 24/1.3 | 메뉴: 18/1.5)
