01 · DESIGN TOKEN

반복되는 값을 이름으로 관리하고,
역할에 맞게 사용합니다.

값을 직접 사용

이렇게 만들면

제목 32px본문 18px글자색 #111111보조글자 #666666버튼색 #635BFF

새로운 화면을 만들 때마다 값을 직접 찾고 선택해야 합니다.

역할로 사용

이렇게 만들면

Heading / MDBody / MDText / DefaultText / MutedBackground / Accent

새로운 화면에서도 같은 역할을 찾아 일관되게 사용할 수 있습니다.

!
반복되는 모든 값을 토큰으로 만들 필요는 없습니다.
처음에는 관리하기 좋은 핵심 값부터 등록하고, 작업하면서 필요한 토큰을 추가합니다.
02 · COLOR

먼저 Color 기준을 정합니다.

프로젝트에서 사용할 색상을 역할에 따라 정하고, Figma의 Color Style 또는 Variable로 등록해 사용합니다. 필요에 따라 같은 기준을 여러 곳에서 공유하거나, 작업하면서 새로운 기준을 추가할 수 있습니다.

COLOR
  • color/accent *브랜드 색상 · 버튼 · 링크 · 선택 상태 #635BFF
  • color/accent-subtle 연한 강조 배경 #F0EFFF
  • Text
  • color/text/primary 중요한 글자 #131313
  • color/text/default *일반 본문 #333333
  • color/text/muted *보조 정보 #666666
  • color/text/accent 강조 글자 #635BFF
  • color/text/inverse *어두운/강조 배경 위의 글자 #FFFFFF
  • Background
  • color/bg/base *페이지와 Section의 기본 배경 #FFFFFF
  • color/bg/surface Card · Panel 등 구분되는 영역 #F5F5F5
  • color/bg/inverse 어두운 배경 #333333
  • color/bg/accent 강조 배경 #635BFF
  • color/bg/accent-subtle 연한 강조 배경 #F0EFFF
  • Border
  • color/border/default *Input · Card · 구분선 등 #CCCCCC
  • color/border/subtle 연한 구분선 #DDDDDD
03 · TYPOGRAPHY

Color를 정한 다음
Text Style을 만듭니다.

글자의 크기와 위계를 정하고, 등록한 색상 기준을 적용합니다. 처음에는 필요한 위계부터 만들고 작업하면서 필요하면 추가합니다.

display / large
가장 중요한 대표 문장
48px · bold · 1.2 Hero의 핵심 메시지, 브랜드 슬로건
heading / large
큰 영역의 제목
36px · bold · 1.3 Section 제목, 큰 콘텐츠 제목
heading / medium
콘텐츠 제목
28px · bold · 1.4 카드 그룹, 일반적인 콘텐츠 제목
body / medium
기본적으로 읽는 본문
18px · regular · 1.6 일반적인 설명과 콘텐츠
body / small
기본 내용을 보조하는 정보
16px · regular · 1.6 카드 설명, 메타 정보, 추가 안내
label / medium
버튼과 UI의 글자
16px · semibold · 1.4 Button, Tab, Form Label
위 기준을 기본으로 참고해 적용합니다.
화면 크기와 콘텐츠의 위계, 디자인 의도에 따라 조정할 수 있습니다.
본문은 충분한 크기와 가독성을 우선합니다.
데스크톱 본문은 16px 이상을 기본으로 하고, 모바일에서도 13px 미만의 글자는 가급적 사용하지 않습니다.
04 · SPACING

여백과 간격에도
기준을 정합니다.

정해진 Spacing 값을 참고하여
화면의 여백과 요소 사이의 간격을 일관되게 구성합니다.

Spacing

4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 128px

레이아웃을 만들 때 참고하여 비슷한 간격을 반복해서 사용합니다.

간격을 사용할 때

가까운 요소는 작은 간격으로,
서로 다른 그룹은 더 큰 간격으로 구분합니다.

05 · LAYOUT & COMPONENT

레이아웃 & 컴포넌트

레이아웃과 컴포넌트에서는 반복해서 사용할 기준을 정하고 일관되게 적용합니다.

LAYOUT 기준

Max Width

640px / 900px / 1200px

콘텐츠가 지나치게 넓어지지 않도록 최대 너비를 정합니다.

COMPONENT 기준

Radius

라운드는 컴포넌트 안에서 같은 기준을 사용합니다.

예: Button과 Input은 같은 Radius를 사용하고, Card는 더 크게 사용하는 식으로 컴포넌트의 성격에 맞춰 정합니다.

Radius 값을 정할 때도 Spacing에서 사용하는 4px 단위 등을 참고하면 서로 어울리는 기준을 만들기 쉽습니다.

!
필요해지면 나중에 토큰으로 확장할 수 있습니다.
06 · BORDER

Border도 역할을 나눠 사용합니다.

같은 테두리를 무조건 반복하는 것이 아니라, 얼마나 눈에 띄어야 하는지에 따라 기준을 나눕니다.

Border / Subtle

있기는 하지만 강하게 보일 필요 없는 경계

Card · List · Section

Border / Default

사용자가 명확하게 구분해야 하는 UI의 경계

Input · Select · Button
필요할 때 확장합니다.
Focus, Error, Disabled처럼 실제 상태가 생기면 그 역할에 맞는 기준을 추가할 수 있습니다.
